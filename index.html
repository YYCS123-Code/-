云端同步（GitHub）
未连接 · 手动上传模式（点「上传到云端」按钮才上传）
使用方法：到 github.com → Settings → Developer settings → Personal access tokens 生成令牌（勾选 repo 权限），粘贴到上面点「连接云端」验证。
令牌只保存在本机浏览器，不会写进网页或泄露；每台设备粘贴一次即可。
手动上传模式：数据每次修改自动保存到本机 IndexedDB；只有点击「上传到云端」时才会上传到 GitHub 仓库的 data.json。换设备时可点「从云端拉取」恢复数据。
